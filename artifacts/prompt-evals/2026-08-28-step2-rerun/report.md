# Step 2 三个历史案例真实 AI 复测

## 范围与方法

- 模型：GPT-5.6 Sol，medium。
- 不使用 API；每次 AI 请求均创建独立 Codex 任务。
- 只运行产品 Step 2：需求对齐、背景资料、故事方向、故事大纲。
- 方向选择规则固定为第一张卡，不按质量挑选。
- 测试中不修改 Prompt。背景步骤程序失败时，按生产手动重试边界使用完全相同 Prompt 重试一次。
- 成本主指标使用实际生产 Prompt / 输出的字符和 UTF-8 字节。Codex token 含独立任务的系统上下文，仅作实验环境记录，不能直接当作生产 API 成本。

## 案例

| 案例 | 历史输入 | 预期路由 | 实际结果 |
| --- | --- | --- | --- |
| C02 | 根据《小马宝莉》，创造一个儿童冒险故事 | 原创参与 + 3 个方向 | 背景首次失败，重试后完成大纲 |
| C03 | 给学生讲一下二战的某个故事 | 忠实旁观 + 3 个真实历史事件方向 | 背景首次失败；重试后方向全部收敛到敦刻尔克 |
| C04 | 四名学生组成超级英雄战队，在老师带领下合力击败怪兽，每人都有高光 | 固定主线 + 主线确认卡 + 大纲 | 被误判为探索方向，多生成一次方向卡后完成大纲 |

## 一次性生成率

- 逻辑步骤首次程序通过：10 / 12 = **83.3%**。
- 全部实际 AI 调用程序通过：12 / 14 = **85.7%**。
- 案例端到端一次性程序完成：1 / 3 = **33.3%**。
- 案例端到端一次性业务与质量完成：0 / 3 = **0%**。C02、C03 在背景步骤失败；C04 虽程序完成，但路由错误。
- 各允许一次相同 Prompt 手动重试后：3 / 3 均生成了程序可接受的大纲；严格按产品语义验收仅 C02 可整体接受，C03 方向多样性失败，C04 固定主线路由失败。

独立 Codex 任务共记录 345,686 tokens，其中输入 331,091、输出 14,595；每个任务含约 11,008 cached input tokens 的任务系统上下文，因此不用于比较生产 Prompt 成本。生产成本分析以表中的 Prompt / 输出字节为准。

## 输出质量

### C02 小马宝莉

- 方向质量明显通过：三张卡都有明确问题、行动和直接结果，且不是同一故事换皮。
- 大纲因果连续，课堂人物和两名引用角色映射正确，结局直接解决书车无法到校的问题。
- 成本问题：背景输出世界包加4名候选角色；选定方向只用了暮光闪闪和云宝黛西，但柔柔、碧琪资料仍进入大纲 Prompt。
- 稳定性问题：相同背景 Prompt 第一次要求外部资料且协议错误，第二次却能直接输出完整资料，说明判断与格式都不稳定。

### C03 二战

- 对齐正确识别 factual / faithful / observer。
- 第二次背景输出的四个候选资料本身边界清楚。
- 方向质量失败：四份候选资料最终只使用敦刻尔克，三张方向卡只是海岸、船只、战略结果三个镜头；没有给老师三个真实事件选择。
- 所选敦刻尔克大纲本身事实边界、因果和旁观者规则通过。
- 成本问题最突出：安妮·弗兰克、奥马哈和图灵三份未选资料继续进入方向与最终大纲 Prompt。

### C04 四名超级英雄

- 对齐漏掉老师已经给出的完整固定主线，错误返回 explore_options；这是业务失败，不是文案偏好。
- 多出的方向调用内容本身质量较好，三张卡都保留四人高光并满足问题—行动—结果。
- 第一张方向的 mainCharacters 漏掉持续参与的吞声怪兽；大纲阶段自行补回。
- 大纲质量通过：四名学生各自有可辨识的状态推进，教师负责组织而未替学生解决问题，结局使用前三章建立的声音组合规则。

## 共同根因候选

1. **背景 Prompt 的分支协议不完整。** 文本只给出 `researchPlan` 字段名，没有给对象结构；两次首次失败都返回字符串数组，程序必然拒绝。
2. **背景步骤承担了方向选择。** 面对宽泛作品版本或宽泛历史主题，模型会在“先选具体对象”与“直接准备多个候选”之间摇摆；相同 Prompt 的重试结果完全不同。
3. **faithful 方向规则把“同一既定事件换视角”写成全局规则。** 这适合已指定原作或史实，却错误覆盖了宽泛 factual + explore_options，本应跨事件选方向的场景。
4. **fixedPlot 识别门槛失效。** C04 已包含人物结构、共同目标、最终结果和逐人贡献，仍被归类为探索方向。
5. **资料没有在选定方向后裁剪。** 未被方向使用的候选资料继续进入大纲，直接放大输入成本。

下一轮应先讨论这些共同根因的修复优先级，不针对案例增加作品名或题材专属规则。
