# Step4 首轮真实模型回归：S4-C01 冰雪奇缘

- 生产 AI 调用：1 次正文调用；0 次修复；0 次练习 AI。
- 程序一次性生成率：100%（1/1）。
- 严格质量一次性生成率：0%（0/1）。
- 结果属于假阳性：生产校验会直接进入 `ready`，但教学题目仍有语义错误。
- 测试编排另有 1 次 `HARNESS_ERROR`，已记录且不计入产品准确率。

- JSON、协议版本、章节 ID、段落数、固定槽位：通过。
- 三章词数：119 / 115 / 117；各段均在 acceptedRange。
- Main Idea：127 词，在 110–130 acceptedRange。
- 计划知识点 ID 覆盖：通过。
- 因此现有生产流程不会触发统一修复。

## 质量问题

1. **知识点标签与真实题目不一致。** 第二章 `speak` 被标成 Present Continuous，但完成句是 `asked them to speak`；`spotted` 被标成 Present Perfect，但完成句是一般过去时。第三章 `cleared`、`held` 被标成 be going to，`pulled` 被标成 will，完成句均为一般过去时。
2. **目标时态反向破坏故事时间线。** `The bell will warn the people, who reached shelter...` 同句把尚未发生的警告和已经避难并列，逻辑不自然。
3. **干扰项质量偏低。** `will clearing`、`am going clear` 等是明显残缺结构，对 B2 学生几乎没有诊断价值。
4. **历史脏数据暴露。** 学生名 `2` 被模型忠实保留，但成文观感差。这不是本次模型偏离，而是旧数据未经过当前英文名约束。
5. **篇幅整体稳定。** 第一章首段 54 词，低于 preferredRange 下界 55 一词，但在 acceptedRange 内；不应因此消耗修复调用。

## 根因

当前程序只检查 `knowledgePointKey` 是否属于本章、是否覆盖全部目标知识点，不检查“槽位拼回完整句后是否真的构成该语法”。Prompt 也只说标签要来自本章，没有明确要求知识点按“完整句结构”判定。模型因此可以靠标签满足覆盖率，并为强塞时态扭曲叙事。

## 建议的全局修复

- Prompt 增加一条短规则：每个语法槽位的 `knowledgePointKey` 必须由“模板上下文 + answer”组成的完整结构真实体现；叙事时态冲突时，把目标时态自然放入人物对话、计划、预测或当前观察，不改写事件时间线。
- 干扰项规则改为：形式完整、同一语法维度、在当前上下文中仅答案正确；禁止用缺助动词/缺 `to` 等残缺结构制造显而易见错误。
- 程序为时态类知识点增加轻量结构校验，覆盖 Present Continuous、Present Perfect、will、be going to 等可确定模式；继续保留 acceptedRange，避免因 1–2 词偏差触发昂贵修复。
- 不增加第二个 AI 质检调用；先靠一次生成 Prompt + 确定性结构校验提高真实一次通过率。
