## 根因判断

原失败不是 JSON 格式错误。两次输出均为 49 个非空 Unicode 字符，但其中包含系统强制使用的英文人物名；按展示宽度实际只有 41、42 单位。程序此前把每个 ASCII 字符按一个汉字计量，同时 Prompt 又把 2–3 个事件、承接局面、行动和结果都写成必做项，形成跨案例契约冲突。

候选 v1 已消除长度误判，但暴露出更上游的因果问题：已选方向要求寻找被困船队，却只把“冰桥抵达港口”定义为结果，未说明这如何让船队脱困。大纲继承了这个不闭合的方向并改成“船员上岸”。因此下一步不应继续给大纲 Prompt 添加结局补丁，而应先审计方向卡的“问题—行动—结果”是否闭合。

另一个明显成本放大点是背景资料：单作品被拆成 4 份后，方向 Prompt 增至 8,581 字节，大纲 Prompt 增至 15,194 字节；其中未选择的雪宝资料仍进入大纲前背景集合。

## Prompt 修复静态结果

- C01 方向 Prompt：3,869 → 3,839 字符，8,581 → 8,467 UTF-8 字节；在增强因果验收标准的同时减少 30 字符 / 114 字节。
- 删除方向生成与单卡修订中的重复“完整因果”句，不新增 AI 自检或自动重试。
- 原创故事新增的是跨题材结果标准，不含《冰雪奇缘》、冰桥或船队等案例词。
- 方向、长度策略、复杂度回归和大纲校验共 58 项测试通过；目标 ESLint 与中文乱码扫描通过。
