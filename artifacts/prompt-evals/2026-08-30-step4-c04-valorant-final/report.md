- 历史案例：`港口里的镜面 Boss / The Mirror Boss at the Harbor`，历史课程 `cmsvp6m880001qcvoz99bw7zj`，此前 Prompt 评测未使用。
- 当前知识点：Essential Grammar in Use, Fourth Edition, A1–B1；Unit 14、Unit 8、Unit 54。
- 生产配置：gpt-5.6-sol Low → High → Medium。

## 结果

- 配置路径 3/3 次调用首次通过，无修复调用。
- 正文 3/3 章、Main Idea、30/30 个正文槽位通过结构校验和逐句人工回填。
- 章节题 12/12、课后题 5/5 通过程序校验；答案和全部干扰项逐项回填后，英语、时态、唯一答案及知识点绑定均通过。
- 输入 20,073 字符，输出 13,072 字符，合计 33,145 字符；顺序耗时 212.896 秒。

## 决策记录

同一候选稿的 Medium 终审虽然通过程序校验，但 `copied / was copying` 在一个题目语境中都可成立，严格内容正确率未达标。High 终审把该干扰项改为当前语境中不成立的标准词形，同时修正 Unit 54 的局部表达，因此第二次调用固定使用 High。该 Medium A/B 调用保留在 `call-02-review/`，不计入最终配置路径的一次性生成率。

Prompt 压缩只删除重复上下文和重复输出，不删除决定英语质量的审校标准：第二次调用传紧凑章节规格并只输出补丁与最终槽位；第三次调用仅传一份课程级知识点字典，各章和课后传知识点短键。

## Medium → High 成本归档

同一候选稿、相同 8,521 字符输入的 A/B 中，Medium 输出 5,022 字符、耗时 98.302 秒；High 输出 4,630 字符、耗时 120.170 秒。High 的可见输出减少 7.8%，可见输入输出总量减少 2.9%，耗时增加 22.2%。

本轮通过独立 Codex 对话执行，没有 API token usage，因此不能把 reasoning 增量伪装成精确账单。按 2026-08-30 GPT-5.6 Sol 官方输出单价 $20 / 百万 tokens 作敏感性计算，每增加 1,000 个 reasoning tokens 约增加 $0.02；实际生产成本以所用网关返回的 input、output 和 reasoning usage 为准。鉴于 High 在同一候选稿上消除了 Medium 遗留的双答案问题，当前决策保持第二次调用为 High，并优先保证一次性内容正确率。
