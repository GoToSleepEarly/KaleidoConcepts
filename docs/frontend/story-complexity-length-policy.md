# 故事复杂度与中英文篇幅统一策略

## 结论

- 新生成、重置和主动再生成只允许 `3–5` 章。旧课程保持可读，不自动改写；发起新操作时按最近的合法边界归一化。
- 课程时长不参与故事或正文篇幅计算。遗留 `durationMinutes` 只用于旧数据兼容。
- 故事复杂度是结构上限，不是冲突、事件或反转配额；所有档位只保留一条主要主线。
- Step 2 先依据 CEFR 与故事复杂度确定每章英文容量，再派生中文大纲容量；Step 3 允许老师调整英文目标；Step 4 始终读取老师最终值。
- 章节数只影响全课容量和整体中文概要长度，不改变每章英文目标。
- 每章正文可配置 1–3 页，一个正文页对应一个段落和一张章节配图。正文题量、章节练习和课后练习不参与正文页数计算。

## 故事复杂度

| 档位 | 面向老师的理解 | 结构上限 |
| --- | --- | --- |
| `clear_linear` | 精简·清晰线性 | 类似 6–10 岁儿童可理解的童话：一个目标，一条行动线，直接结果；不强制冲突 |
| `conflict_driven` | 标准·冲突推进 | 初中生可理解的线性故事；允许一个核心矛盾、受挫、选择或策略调整 |
| `layered` | 丰富·多层叙事 | 高中生可理解的较复杂故事；允许复杂动机、信息回收和有铺垫的反转 |

概念、事实与忠实改编仍受内容边界优先约束：事实课不为复杂度虚构冲突；忠实改编不改变原作或史料的事件、因果、角色决定与结局。

## 每章英文目标矩阵

| CEFR | 精简 | 标准 | 丰富 |
| --- | ---: | ---: | ---: |
| Starter | 70 | 80 | 90 |
| A1 | 80 | 90 | 100 |
| A2 | 90 | 110 | 120 |
| B1 | 110 | 130 | 140 |
| B2 | 130 | 150 | 170 |
| C1 | 140 | 160 | 180 |
| C2 | 150 | 170 | 180 |

老师可配置硬边界为 `60–200` 词。系统推荐目标仍最高 180 词，推荐区间为矩阵目标上下 20 词并截断在系统推荐范围内；推荐区间外只提示表达不足或阅读负担风险，硬边界外阻止保存与确认。

英文生成使用两层范围：

- AI 期望区间：约为目标的 `90%–110%`，且至少上下保留 10 词空间。
- 程序验收区间：约为目标的 `85%–120%`，绝对限制 `50–210` 词。

示例：70 词目标的期望 / 验收区间是 `60–80 / 60–85`；150 词是 `135–165 / 130–180`；180 词是 `160–200 / 155–210`。程序容错不反向提高老师可配置上限，也不改变段落数。

## 中文展示容量

中文按近似展示宽度计量：汉字和全角字符计 `1` 个展示单位，ASCII 字符计 `0.5` 个展示单位，空白不计。这样系统要求使用的英文人物名不会被按等量汉字高估。

中文只有推荐上限和模型生成上限，没有下限，不填充、不程序截断。程序验收在模型生成上限外保留 `12%` 确定性容错（向上取整）；该容错不写入生成目标，也不鼓励模型主动用满。

- 方向 `hook`：推荐 70 字，硬上限 90 字，通常 2 个短句。
- 整体大纲 `summary`：3 / 4 / 5 章分别为 `70/95`、`80/105`、`90/115`，通常 2–3 个短句。
- 单章 `whatHappens`：英文目标 70–90、100–130、140–160、170–180 时，分别为 `35/45`、`45/55`、`55/70`、`60/80`。默认 1 个短句、必要时最多 2 句，只保留决定性行动和直接结果；2–3 个事件是结构上限，不是生成目标。

## 正文段落

- 每章目标不超过 90 词：1 段。
- 系统按 CEFR 课堂投屏密度推荐 1–3 页；老师可以覆盖推荐值，超出舒适密度只提示、不阻止。
- 老师不能独立编辑段数；前端展示与服务端保存均从最终英文目标重新派生。
- 每段对应一个正文内容页和一张章节图片；习题只嵌入自然语境，不增加正文段落。

## 数据流与兼容

1. Step 2 保存 `storyComplexity` 与 `chapterCount`。程序保留完整篇幅策略供 UI、校验和兼容读取；方向和大纲 Prompt 只接收生成所需的 `chapterTargetWords`、`generationRange` 及对应中文上限，不暴露教师编辑范围、程序验收范围或绝对容错范围。
2. Step 3 用相同策略初始化每章 `targetWordCount`，再按 CEFR 页密度推荐 1–3 页；老师可分别修改词数和页数。
3. Step 4 将老师目标转换为 AI 期望区间与程序验收区间。首次生成、段落预算、失败识别和修复全部调用同一纯函数。
4. 已保存旧大纲、旧规划和旧正文不因读取而改写。旧章节数仍可展示；新消息、重置或再生成必须使用 3–5 章。旧规划的超界词数可读取，但重新确认前需要调整到 60–200。

## 回归验证

固定回归集包含全部 16 个历史案例和 15 个构造案例，覆盖 narrative / concept / factual / faithful、Starter–C1、三档复杂度、单人 / 群像 / 八名学生、科学概念、儿童心理、真实历史、信息密集与事件密集场景，并新增：

- A2、精简、5 章：四名学生时空穿越冒险。
- B2、标准、5 章：两名学生以观察者身份见证《浮士德》第一部核心剧情。

自动化测试负责证明字段边界、映射、Prompt 约束、段落派生、校验与兼容行为；独立 Codex 5.6 Sol 任务使用完整生产 Prompt 做语义预检。后者能发现可读性、忠实度和结构过载问题，但不等于真实生产 API 输出一致性保证，生产稳定性仍依赖固定模型版本、持续 eval 与上线后抽样。
