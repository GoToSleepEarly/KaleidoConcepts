# 预设库：主题灵感 / 语法库

## 模块目标

预设库维护两类可复用选项：

- 主题灵感：供 Step2 “从灵感库开始”选择，用来让 AI 生成 3 个故事方向。
- 语法库：维护供 Step1 选择的课程语法知识点；教师配置界面使用中英文双语名称。

主题灵感不是课程最终主题。最终主题来自 Step2 确认后的故事大纲和最终文案。

## 页面

| 页面 | 路由 | 用途 |
| --- | --- | --- |
| 主题灵感库 | `/themes` | 维护 Step2 可选主题灵感 |
| 语法库 | `/grammar` | 维护 Step1 可选语法点 |

## 主题库范围

- 主题库页面管理三类独立预设：主题灵感 `theme`、故事类型 `story_type`、故事氛围 `story_tone`。
- 主题灵感使用两级结构：主题大类 `category` + 主题方向 `label`，不增加第三层或说明字段。
- 故事类型和故事氛围是平级单层列表，不与主题大类混存，也不依赖分类名称判断用途。
- 大类用于浏览，主题方向用于约束 AI 的创作范围；主题方向不包含固定主角、任务、冲突或结局。
- Step2 每次只选择一个主题方向，再结合可选的故事类型、故事氛围、课程人物和补充要求生成 3 个实质不同的故事目标。
- “任意主题”是 Step2 的系统入口，不作为主题库记录保存。

| 主题大类 | 主题方向 |
| --- | --- |
| 校园与成长 | 新环境、同伴关系、校园活动、兴趣探索、规则与选择 |
| 家庭与日常 | 家庭分工、代际交流、节日庆祝、生活变化、共同回忆 |
| 自然与生态 | 动物世界、植物生长、海洋生态、天气与气候、环境保护 |
| 科学与未来 | 太空探索、机器人、发明创造、科学实验、未来城市 |
| 奇幻与想象 | 魔法世界、神秘生物、隐藏世界、时间旅行、神话传说 |
| 历史与文化 | 古代文明、博物馆与文物、节日与习俗、传统技艺、世界旅行 |
| 社区与社会 | 职业体验、社区服务、公共交通、志愿行动、城市问题 |
| 运动与挑战 | 团队运动、个人突破、公平竞争、户外挑战、健康生活 |

## 主题库交互

### 管理页

- 全局搜索同时匹配主题大类和主题方向。
- 分类筛选展示每个大类的记录数量，主题方向按大类分组展示。
- 新增和编辑时必须填写主题大类与主题方向；大类可复用已有值，也可直接输入新值。

## 管理页视觉与分页优化（2026-08-13）

本轮同时优化 `/themes` 与 `/grammar`，遵循课程首页已确认的明亮 AppShell、字号体系和 iPad / Web 横屏适配标准。不得新增不改变决策的说明文案。

### 共同布局

- 删除内容区顶部重复说明；AppShell 已提供页面标题与副标题，内容区只保留搜索、分类浏览、新增入口和数据内容。
- 搜索框位于首行左侧，新增按钮位于首行右侧；1024 × 768 横屏保持同一行，不产生横向滚动。
- 分类 Tab 与搜索合并为一个紧凑工具区，不再使用独立的大号说明卡片。
- 分类内容继续按组展示，但压缩分组外边距、标题区高度、卡片高度和栅格间距；不缩小现有 14 px 主文字和 12 px 辅助文字。
- 主题与语法使用同一套结构、间距、分页和交互，仅字段内容不同。

### 按类别分页

- 分页单位是“类别”，不是单条主题方向或语法点；同一类别下的全部条目必须在同一页完整展示，不能拆页。
- 默认每页显示 5 个类别。
- “全部”状态按类别排序后分页；选择具体分类时只展示该分类，不显示无意义的分页控件。
- 全局搜索跨全部类别匹配，并将匹配结果按类别重新分组；搜索结果仍按每页 5 个匹配类别分页。
- 切换分类、修改搜索词、新增或删除导致类别集合变化时回到第 1 页；当前页超出总页数时回退到最后一页。
- 数据量只有 40 / 57 条且同时被 Step1 / Step2 选择器复用，本轮管理页采用前端“类别分页”，不改变 `GET /api/presets` 的完整列表合同。

### 新增主题的兼容选择

- 主题大类明确拆成“选择已有 / 新建大类”两种互斥状态，避免把下拉选择与自由输入混在同一控件中。
- “选择已有”使用标准下拉框；“新建大类”使用纯文本输入框，两者占用完全相同的宽度和位置。
- 主题方向始终使用普通文本输入；已有主题方向从卡片进入编辑，不在新增流程中混入更新行为。
- 语法库分类使用同样交互，对应文案为“选择已有 / 新建分类”。

### 验收尺寸

- 1024 × 768、1280 × 800、1366 × 768、1440 × 900、1920 × 1080。
- 所有尺寸无页面横向滚动；1024 横屏下分类工具区可水平滚动，但不得挤压搜索和新增按钮。
- 五个类别及分页区在常见 768 / 800 px 高度下保持合理密度；页面允许正常纵向滚动，不压缩正文可读性。

### Step2 主题选择器

- Step2 必须从主题库 API 读取数据，不再维护硬编码主题选项。
- Step2 分别读取 `GET /api/presets?kind=theme`、`story_type` 和 `story_tone`；类型和氛围均允许本次临时自定义，自定义值不自动写回主题库。
- 主题选择使用可搜索、可按大类筛选的单选卡片，不使用长下拉框。
- 选择结果展示为“主题大类 / 主题方向”，提交给 AI 时同时传递两级名称。
- 输入搜索词时搜索全部大类；切换大类时清空搜索词。

## 语法库范围

- 本期只维护语法知识点，不纳入词汇、发音、阅读策略、写作结构或考试题型。
- 本期内容覆盖常见 A1-B2 教学范围，但不为单个语法点保存或展示建议等级。
- 每个语法点表达一个独立教学目标，不建立 `Present Perfect vs. Past Simple` 一类对比型或复合型条目。
- 教师配置界面显示中文名称和英文名称；学生课件与 PDF 只显示英文名称。

## 语法库交互

### 管理页

- 页面顶部提供中英文全局搜索，输入后搜索全部分类，不受当前分类筛选限制。
- 分类筛选展示各分类数量；清空搜索后回到当前分类浏览状态。
- 语法点使用紧凑双行卡片展示，中文名称为主标题，英文名称为副标题。
- 新增和编辑时分别填写中文名称与英文名称，不把双语名称拼接进同一个字段。

### 课程选择器

- 支持按中文名称或英文名称搜索。
- 支持按分类筛选；全局搜索结果同时展示所属分类。
- 已选择项集中汇总，切换分类或搜索时不丢失选择状态。
- Step1 和教学规划等教师配置界面显示中英文名称；学生课件与 PDF 继续只显示英文名称。

## 数据约定

- 现有 `label` 继续保存英文名称并作为 AI 生成、练习绑定和课件展示使用。
- `PresetOption` 新增可选中文字段 `labelZh`；创建或更新 `grammar` 类型时必须提供，`theme` 类型不使用该字段。
- API 返回的 `PresetOption` 同时包含 `label` 和 `labelZh`；搜索同时匹配两个字段。
- 本次字段变更必须通过 Prisma migration 发布，现有语法数据由 migration 或受控回填补齐中文名称。

## API

### `GET /api/presets?kind=theme|grammar`

返回：

```ts
{ presets: PresetOption[] }
```

排序：`category` 升序 -> `sortOrder` 升序 -> `label` 升序。

### `POST /api/presets`

创建主题方向或语法点。两种类型都必须提供 `category`；`grammar` 还必须提供英文 `label` 和中文 `labelZh`。

### `PUT /api/presets/:id`

更新名称和分类。`kind` 不可改变；`grammar` 的双语名称必须同时保存。

### `DELETE /api/presets/:id`

软删除，写入 `archivedAt`。

## 使用边界

- Step1 只读取 `grammar`。
- Step2 启动表单只读取 `theme`。
- 预设删除不影响已经保存的课程或已生成的教案文本。
- 当前不做拖拽排序、批量导入导出或多级主题树。
- 当前不做 CEFR 等级标签、雅思/托福标签或语法点之间的依赖关系。
