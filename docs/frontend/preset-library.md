# 预设库：主题灵感

## 模块目标

预设库只维护 Step 2 创作入口使用的主题灵感、故事类型和故事氛围。

语法知识点不再属于可编辑预设。其权威来源、只读页面、课程选择器、数据结构和兼容规则统一见 `docs/frontend/grammar-knowledge-library.md`。

主题灵感不是课程最终主题。最终主题来自 Step 2 确认后的故事大纲和最终文案。

## 页面

| 页面 | 路由 | 用途 |
| --- | --- | --- |
| 主题灵感库 | `/themes` | 维护 Step 2 可选主题灵感、故事类型和故事氛围 |

`/grammar` 是独立的系统只读知识库，不复用本模块 CRUD。

## 主题库范围

- 主题库页面管理三类独立预设：主题灵感 `theme`、故事类型 `story_type`、故事氛围 `story_tone`。
- 主题灵感使用两级结构：主题大类 `category` + 主题方向 `label`，不增加第三层或说明字段。
- 故事类型和故事氛围是平级单层列表，不与主题大类混存，也不依赖分类名称判断用途。
- 大类用于浏览，主题方向用于约束 AI 的创作范围；主题方向不包含固定主角、任务、冲突或结局。
- Step 2 每次只选择一个主题方向，再结合可选的故事类型、故事氛围、课程人物和补充要求生成 3 个实质不同的故事目标。
- “任意主题”是 Step 2 的系统入口，不作为主题库记录保存。

## 管理页交互

- 全局搜索同时匹配主题大类和主题方向。
- 分类筛选展示每个大类的记录数量，主题方向按大类分组展示。
- 新增和编辑时必须填写主题大类与主题方向；大类可复用已有值，也可直接输入新值。
- 搜索框位于首行左侧，新增按钮位于首行右侧；1024 × 768 横屏保持同一行，不产生页面横向滚动。
- 分类 Tab 与搜索组成紧凑工具区；分类内容按组展示，不使用解释型大卡片。

### 按类别分页

- 分页单位是主题大类，不拆分同一大类下的主题方向。
- 默认每页显示 5 个大类。
- “全部”按大类排序后分页；指定大类时不显示分页。
- 搜索跨全部大类匹配，结果重新按大类分组并分页。
- 分类、搜索词或数据变化后回到第 1 页；当前页越界时回退到最后一页。
- 数据量较小，继续由前端按类别分页，不改变完整列表 API。

### 新增主题

- 主题大类拆成“选择已有 / 新建大类”两种互斥状态。
- “选择已有”使用标准下拉框；“新建大类”使用文本输入，两者占据同一位置。
- 主题方向始终使用普通文本输入；已有方向从列表进入编辑。
- 删除使用项目内确认弹窗，不使用浏览器原生确认框。

## Step 2 主题选择器

- 分别读取 `GET /api/presets?kind=theme`、`story_type` 和 `story_tone`。
- 主题使用可搜索、按大类筛选的单选卡片，不使用长下拉框。
- 故事类型和故事氛围使用同类单选弹窗，支持“不限”、预设和本次临时自定义。
- 自定义值为空时不能确认，且不自动写回主题库。
- 主题回显为“主题大类 / 主题方向”，提交 AI 时同时传递两级名称。
- 输入搜索词时搜索全部大类；切换大类时清空搜索词。

## 数据与 API

主题预设继续使用 `PresetOption`，语法知识点不再写入或读取该模型。

### `GET /api/presets?kind=theme|story_type|story_tone`

```ts
{ presets: PresetOption[] }
```

排序为 `category`、`sortOrder`、`label` 升序。

### `POST /api/presets`

创建主题方向、故事类型或故事氛围。主题方向必须包含 `category`。

### `PUT /api/presets/:id`

更新名称和分类，`kind` 不可改变。

### `DELETE /api/presets/:id`

软删除并写入 `archivedAt`。删除不影响已经保存的课程或大纲文本。

## 使用边界

- Step 2 读取 `theme`、`story_type` 和 `story_tone`。
- Step 1 和教学规划不得通过预设 API 读取语法知识点。
- 当前不做拖拽排序、批量导入导出或多级主题树。
