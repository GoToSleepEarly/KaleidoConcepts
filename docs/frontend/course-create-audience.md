# 课程创建阶段一：基础信息

## 模块目标

阶段一确认课程管理名称、授课老师、学生、英语难度和全课知识点，并创建课程记录。页面不向老师引入“草稿”概念。

阶段一面向用户命名为“基础信息”。页面不展示内部工作流、数据结构或 AI 生成说明，只通过清晰布局、选择状态和必要反馈让教师完成第一步。

阶段一不配置故事、章节知识点分配、题型、题量或视觉风格。英语难度、Grammar in Use 书籍版本和全课知识点是老师明确给出的教学范围，也是后续流程的唯一真相源。全课知识点表示希望尽可能覆盖的范围，不承诺每项最终一定被分配。保存基础信息本身不产生 AI 费用；人物形象生成仅在用户明确触发时产生费用。

语法来源、Unit 合并、只读目录和旧课程兼容统一遵循 `docs/frontend/grammar-knowledge-library.md`。

## 路由

- 新建：`/courses/new`
- 已创建课程返回编辑：`/courses/:id/create/audience`
- 保存成功后：`/courses/:id/create/story-outline`

课程创建统一使用正式 `/courses` 路由。

## 字段

必填：

- 课程名称
- 老师：单选 1 位
- 学生：至少 1 位
- 英语难度：Starter / A1 / A2 / B1 / B2 / C1 / C2
- 全课知识点：至少 1 个

不在本阶段收集：

- 故事主题或参考剧情
- 第三方人物 / IP
- 题型和题量
- 视觉风格

课程名称只用于课程管理。后续故事标题或课件展示标题不得覆盖课程名称。

## 页面结构

- 顶部流程使用紧凑的分段步骤 Tab，合并到 AppShell 的“新建课程”标题行，不在正文单独占据一行。当前步骤使用品牌色实底；可返回步骤使用白底、边界、悬停和按压反馈；未解锁步骤灰化。控件自身表达可点击性，不增加说明文字。iPad 横屏隐藏步骤编号以完整显示名称，PC 宽屏显示编号和名称。
- 顶部流程图只表达流程位置和可返回节点，不展示“下一步”，下一步动作只由页面底部主按钮承担。
- 当前节点使用轻量高亮圆点和文字强调；已完成节点在已有课程 ID 的页面中可点击返回；当前节点不可点击；未解锁节点禁用。
- Step1 当前存在缺失项时，即使课程历史状态曾到达 Step2，也只突出 Step1，后续步骤不显示完成态且不可直接进入；补齐后恢复已有可达步骤。
- 顶部流程图使用中性白底和细描边，不使用说明文案、渐变装饰、大卡片、粗分割线或大面积色块，避免抢占页面主表单视觉重点。
- AppShell 在新建课程及课程创建步骤只显示当前任务标题，不显示重复解释流程的副标题。
- 页面主标题为“基础信息”。
- 页面主标题下不放解释型说明文字。
- 表单分为五个视觉重点：
  - 课程名称：带图标，突出输入框。
  - 老师：单独区域，只展示当前已选老师或“添加老师”。
  - 学生：单独区域，只展示当前已选学生或“添加学生”。
  - 英语难度：使用与主题库一致的紧凑品牌色等级 Tab；新课程默认选中 A2。详情分为“综合能力”和“语法表现”，分别转述 CEFR 综合能力与 grammatical accuracy 描述。Starter 明确标记为产品起步级、参考 Pre-A1，不冒充 CEFR 或 Cambridge 官方等级。界面内完整表达选择依据，不提供标题区外链。
  - 全课知识点：通过 Grammar in Use 大弹窗一次选择。课程难度只决定默认打开的书，老师可以切换；一门课程只能选择一本书。桌面按 Section / 知识点列表 / 已选区三栏展示，Pad 与手机按只读知识库契约自适应。搜索匹配当前书的系统标题、Unit 编号和来源 Unit 官方标题；跨 Section 选择持续保留。
- 五个表单区块统一使用与人物库、主题库分组一致的浅蓝顶栏，图标、标题和区块操作放在顶栏，具体输入与选择内容放在白色内容区。
- 底部提供取消 / 下一步。

页面不直接铺开全部人物卡片，不用长段说明替代可见操作。

课程名称、老师、学生、英语难度和全课知识点均使用统一的必填 `*` 标记。老师和学生标题右侧均不显示“未选择”，完成状态通过卡片、添加按钮和底部首个阻断原因表达。

全课知识点超过 10 个时显示非阻断提示：

```text
知识点较多，课程中可能难以充分展开。AI 会结合英语难度和故事内容推荐每章重点，你可以在教学规划中调整。
```

该提示不替老师删除知识点，也不阻止进入下一步。

## 人物选择

### 无人物时的首次引导（2026-08-20）

- 仅在新建课程页首次加载时，同时查询启用老师和学生是否存在；不在编辑已有课程时打断老师。
- 如果老师或学生任一类型为空，在表单顶部显示阻断型引导，明确列出缺少“老师”“学生”或两者，并提供“前往人物档案”主操作。
- 引导文案使用“创建课程前，请先创建老师和学生人物，并完成人物形象”，直接说明课程的真实前置条件；不等老师点击空选择器后才发现无法继续。
- 人物选择器为空时保留相同结论，并提供可点击的“前往人物档案创建老师 / 学生”，不能只显示无操作的空状态文字。
- 跳转人物档案属于显式导航；新建课程页尚未保存的其他输入不会跨页面承诺保留。老师返回新建课程页后重新查询人物状态。

- “添加老师”打开单选弹层。
- “添加学生”打开多选弹层，点击确认后应用选择。
- 支持搜索、最近使用和分页加载。
- 选择器只展示启用人物。
- 选择器使用与人物档案一致的三列紧凑资料卡，展示 2:3 人物形象、姓名、英文名、年龄和性别，避免双列宽卡产生无效空白。
- 只有存在可用当前形象的人物可以选中。无形象人物显示“形象未生成”和小型“创建形象”按钮，选择控件禁用；点击创建后在当前 Step1 内打开人物编辑弹窗，保存后返回选择器并刷新人物，不离开课程、不丢失已填内容。
- 已选人物以相同视觉结构的固定最大宽度资料卡展示，不使用横向通栏；单个老师卡也不撑满整行，老师和学生都显示真实当前形象。
- 已选卡保留固定宽度，人物信息在图片右侧居中形成稳定重心；操作区使用“编辑”和明确的垃圾桶移除图标，不使用含义模糊的 `X`。
- 人物姓名使用卡内最高信息权重，英文名和年龄性别次之；编辑、移除属于低频操作，收进右侧的小型图标按钮，不占据人物信息区。
- 已选卡的编辑、移除图标固定在卡片右侧垂直居中；人物信息区使用低饱和浅紫底。年龄和性别拆成独立的有色标签，并与人物档案保持一致，避免白色标签融入卡片背景。
- Step1 使用更紧凑的区块间距和卡片内边距；顶部步骤 Tab 提升字号与高度，作为课程创建流程的核心导航。
- 有形象的人物整张卡片就是选择控件，不再显示重复的“选择”按钮；选中态通过品牌色边界和右上角勾选标识表达。
- 无形象人物使用同样的居中信息结构和年龄、性别标签，额外显示“形象未生成”状态与小型“创建形象”按钮。
- 人物选择弹窗宽度保留三列卡片，但高度随内容收缩，仅在人物较多时滚动，避免数据较少时出现大块底部空白。

人物卡只展示决策所需信息：

- 当前形象或默认头像
- 中文名 / 英文名
- 年龄 / 性别
- 编辑入口

由于基础资料保存前已经强校验，本阶段不显示“缺英文名、缺年龄、缺外貌”等资料缺失标签。

人物一旦被选入课程就必须存在可用当前形象；前端禁止选择，服务端保存时再次校验。课程人物卡不展示“未创建形象 / 已创建形象”等状态描述。

## 难度与知识点选择

- 难度顺序固定为 `Starter → A1 → A2 → B1 → B2 → C1 → C2`。
- A1 / A2 使用 CEFR 的“基础使用者”，B1 / B2 使用“独立使用者”，C1 / C2 使用“熟练使用者”。界面能力摘要是对 Council of Europe Global Scale / Self-assessment Grid 的简明中文转述，不声称为官方中文译文。
- CEFR 描述完整语言沟通能力；Grammar in Use 的 A1–B1、B1–B2、C1–C2 只用于说明教材适用范围，不能代替 CEFR 等级定义。
- Step 1 不再向老师收集课程时长。为兼容既有生成和数据合同，新课程内部沿用 60 分钟默认值，旧课程保留原值；该值不作为本页教学决策项展示。
- Starter / A1 / A2 默认进入 Essential Grammar in Use；B1 / B2 默认进入 English Grammar in Use；C1 / C2 默认进入 Advanced Grammar in Use。
- 默认书籍只是 landing，不是限制。B1 老师可切换到 Essential Grammar in Use，其他难度也可按教学判断切书。
- 已选择知识点后切书必须二次确认；确认后原子切换书籍并清空已选知识点，取消时两者都不改变。
- 页面回显已选书名、版本和知识点英文标题。来源 Unit 可查看；不保存或展示中文知识点名。
- 已选知识点使用有边界的浅品牌色标签，避免纯白标签与页面背景重合。超长标题保持单行标签：精细指针悬停时仅对实际溢出的标题横向轮动，移出后复位；触屏点击标题展开全文，再次点击收起；Unit 与移除操作固定不动，并遵守 `prefers-reduced-motion`。

## 文案原则

- 用户可见文案只保留任务、选择、状态、错误和恢复动作。
- 不向用户解释“硬约束”“数据真相源”“下游内容”“AI 费用”等内部概念，除非当前操作会产生不可忽略的业务后果。
- 不用说明文字弥补交互不清晰；优先通过分组、按钮标签、禁用原因和选中态降低理解成本。
- 底部操作区只显示当前第一阻断原因或已完成摘要。
- 下游重置、图片生成计费和保存失败属于必须反馈的信息，需要明确但短。

## 交互反馈基线（2026-08-20）

本轮不以“增加动画”替代状态反馈，也不无边界重做全站。先在“创建人物 → 完成人物形象 → 新建课程”核心链路统一以下反馈：

- 点击后立即反馈：提交按钮进入进行中状态并防重复提交。
- 持久化成功可验证：通过按钮文案、局部成功状态或数据变化明确表达成功；不能完成后恢复为点击前原样。
- 失败可恢复：保留输入和当前选择，在操作附近显示原因与重试入口。
- 下一步明确：动作完成但流程尚未完成时，提示唯一下一步，例如“创建人物形象”或“设为当前形象”。
- 长任务可恢复：刷新后从服务端状态恢复等待和轮询，不把浏览器内存当作生成状态真相源。
- 动效只服务于反馈和状态过渡，使用短时颜色、透明度或位移变化，并遵守 `prefers-reduced-motion`。

## 就地编辑

- 点击编辑打开居中弹窗，基础资料与人物形象在同一个界面维护。
- 保存后刷新当前选择中的人物展示。
- 人物形象默认提供照片上传，描述生成作为次选入口；详细外貌设置按需展开。
- 图片生成必须由用户明确点击触发，并在操作前显示会产生一次生成。
- 图片生成失败不影响课程表单和人物基础资料。

## 课程人物快照

课程不能长期直接读取会变化的人物档案作为生成真相源。

保存授课对象时，`CoursePerson` 同时保存：

- `personId`
- 课程角色：老师 / 学生
- 中文名快照
- 英文名快照
- 年龄快照
- 性别快照
- 当前人物形象资产 ID 快照，可为空

结果：

- 人物档案后续修改不会暗中改变已创建课程。
- 在授课对象页重新保存时，课程明确刷新为人物档案最新资料。
- 已发布课程始终可追溯当时使用的人物信息和形象版本。

## 初始状态与按钮

初始状态：

- 课程名称为空。
- 未选择老师。
- 未选择学生。
- 英语难度默认 A2。
- 未选择知识点。
- 下一步禁用。

下一步启用条件：

- 课程名称去除首尾空格后非空。
- 恰好 1 位启用老师。
- 至少 1 位启用学生。
- 英语难度为 Starter-C2。
- 至少选择 1 个有效知识点。

禁用时只展示第一个未完成原因：填写课程名称、添加老师、添加学生或选择知识点。

底部首个未完成原因使用错误色显示，帮助教师快速定位缺失信息；信息完整后恢复中性保存状态。

## API 合同

### `POST /api/courses`

原子创建课程和人物快照。

请求必须携带 `Idempotency-Key`。同一账号和相同 key 重试时返回第一次创建的课程，不重复创建草稿。

```ts
type CourseAudienceInput = {
  title: string;
  teacherId: string;
  studentIds: string[];
  durationMinutes: 30 | 45 | 60;
  englishLevel: "Starter" | "A1" | "A2" | "B1" | "B2" | "C1" | "C2";
  grammarBookEditionId: string;
  knowledgePointIds: string[];
};
```

响应：

```ts
{
  course: {
    id: string;
    lifecycleStatus: "draft";
    currentStage: "story_outline";
  };
}
```

失败：

- `400` 课程信息不完整。
- `404` 人物不存在。
- `409` 人物不可用或角色不匹配。
- `500` 课程创建失败。

创建失败时不留下半完成课程，前端保留全部表单内容。

### `GET /api/courses/:id/audience`

读取课程管理名称、时长、课程人物快照及当前人物档案摘要。

历史快照和当前档案有变化时，响应返回 `profileChanged = true`，但不自动覆盖课程快照。

### `PUT /api/courses/:id/audience`

更新授课对象并刷新人物快照。请求同 `CourseAudienceInput`。

如果故事大纲尚不存在，直接在事务中更新。

如果已存在下游内容：

- 只修改课程名称：直接保存，不影响下游。
- 修改老师、学生、时长、英语难度、书籍版本或知识点：返回 `409`，要求确认重置。
- 请求带 `preserveDownstream = true` 后，在单个事务中更新授课对象和人物快照，并从故事大纲开始标记后续内容为旧版本；故事大纲、教学规划、文案练习、视觉资源、图片和预览发布设置全部保留。任一步数据库写入失败时保留原课程状态。
- 不物理删除已成功图片。

事务失败时课程和全部下游内容保持原状。

## 数据结构

课程状态直接由当前阶段和各模块确认状态表达，不增加并行工作流模式字段。

```ts
type Course = {
  id: string;
  title: string;
  durationMinutes: 30 | 45 | 60;
  englishLevel: "Starter" | "A1" | "A2" | "B1" | "B2" | "C1" | "C2";
  grammarBookEditionId: string | null;
  knowledgePointIds: string[];
  lifecycleStatus: "draft" | "published" | "archived";
  currentStage:
    | "audience"
    | "story_outline"
    | "teaching_plan"
    | "content"
    | "visual_resources"
    | "preview";
  createdAt: Date;
  updatedAt: Date;
};

type CoursePerson = {
  id: string;
  courseId: string;
  personId: string;
  role: "teacher" | "student";
  chineseNameSnapshot: string;
  englishNameSnapshot: string;
  ageSnapshot: number;
  genderSnapshot: "male" | "female";
  visualAssetIdSnapshot: string | null;
  createdAt: Date;
  updatedAt: Date;
};
```

约束：

- 一个课程恰好一个老师关联。
- 一个课程至少一个学生关联。
- 同一人物不能在同一课程中重复关联。
- 英语难度、书籍版本和全课知识点保存在 `Course`，是 Step 2 推荐和 Step 3 教学规划的唯一上游真相源。
- 新课程的 `knowledgePointIds` 必须全部对应 `grammar_in_use` 知识点且属于 `grammarBookEditionId` 指定的同一本书；后续章节只能从这组知识点中选择。
- 老课程允许 `grammarBookEditionId = null` 并保留 legacy 知识点。Step 1 必须完整展示课程名称、人物快照、英语难度和旧知识点名称 / 分类，只隐藏或禁用编辑、选择与保存操作；不得用只读提示页替换原信息。旧知识点通过保存的 ID 回查 `PresetOption`，已归档记录仍可读取；更新接口继续拒绝修改。

## 状态与失败恢复

- 新建页未提交前不创建数据库记录。
- 创建成功后 `currentStage = story_outline`。
- 更新失败不创建新课程，不改变旧快照。
- 人物编辑失败时抽屉保留输入，课程选择保持原状。
- 人物形象生成失败不影响基础资料或课程保存。
- 修改老师、学生、英语难度、书籍版本或知识点且存在后续成果时，使用项目内弹窗动态列出影响范围。用户可以保留后续成果并暂不应用本次修改，也可以应用修改并清理后续成果；不得使用浏览器原生确认框或强制删除。
- 页面重复提交使用 `Idempotency-Key` 幂等保护，避免创建两门相同草稿课程。

## 验收标准

- `/courses/new` 直接进入可填写的基础信息页面。
