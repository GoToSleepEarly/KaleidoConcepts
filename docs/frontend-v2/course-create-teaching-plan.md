# 课程创建阶段三：教学规划

## 文档状态

- 状态：契约已讨论确认，待开发。
- 本文档替代旧版教学规划草稿。
- 本阶段用户可见名称为“教学规划”。

## 模块目标

阶段三负责把已确认的故事大纲配置成确定性的教学规划。

本阶段不调用 AI，不生成英文正文、真实题目、答案、解析、图片 prompt 或课件页面。它只保存后续“文案与练习”阶段需要遵守的配置：

- 全局英语难度。
- 每章目标词数。
- 每章知识点。
- 每章正文是否加入内嵌题。
- 每章是否生成章节练习。
- 是否生成课后练习。
- 各类练习的题型和题量。

成功标准：老师不用理解 prompt、JSON 或内部生成流程，也能快速判断每章最后在课件里大概长什么样，并能用最少操作完成配置。

## 输入边界

必须读取：

- 阶段一课程基础信息：课程时长、老师和学生快照。
- 阶段二已确认故事大纲：章节 id、章节标题和章节摘要。
- 预设知识点库。

前置条件：

- 故事大纲必须已确认。
- 如果故事大纲不存在或未确认，页面提示返回故事大纲阶段。

本阶段不读取 V1 schema，不使用 `/api/v2`，不使用 `workflowMode`。

## 设计原则

- 确定性配置页，不做 AI 生成页。
- 首屏只展示当前任务，不做解释型长文案。
- 不默认英语难度，必须由老师明确选择。
- 知识点按章节手动选择，不分主知识点和补充知识点。
- 默认降低复杂度：正文无题，章节练习开启，课后练习开启。
- 只有老师主动选择“正文加入题目”时，才展示内嵌题配置。
- 预览是 PPT Slide 式当前对象预览，不做全课结构预览。
- 保存草稿不重置下游；确认进入下一步才可能重置下游。

## 页面结构

桌面端使用两栏布局。

### 左侧

左侧承载全局选择和对象导航：

- 英语难度选择：A1、A2、B1、B2、C1、C2。
- 章节列表。
- 课后练习入口。
- “应用到全部章节”批量动作。

章节列表每项展示：

- 章节序号和标题。
- 目标词数。
- 知识点数量。
- 正文模式：无题 / 内嵌题。
- 章节练习状态：开启 / 关闭。

课后练习入口展示：

- 开启 / 关闭。
- 题量。
- 知识点数量。

“应用到全部章节”使用当前章配置覆盖其他章节，包括：

- 目标词数。
- 知识点。
- 正文模式。
- 内嵌题配置。
- 章节练习配置。

该动作需要项目自有弹窗二次确认。确认文案：

```text
将用当前章配置覆盖其他章节。已手动修改的章节也会被覆盖。
```

按钮：

- 保留原配置
- 覆盖其他章节

### 右侧：章节配置

选中章节时，右侧展示：

- 章节标题。
- 章节摘要，只保留帮助判断教学配置的一句话或短段，不展示冗长故事全文。
- 目标词数。
- 知识点多选。
- 正文模式。
- 章节练习配置。
- 当前章 PPT Slide 式预览。

#### 目标词数

每章目标词数直接展示数字，不使用“短 / 标准 / 长”作为主控件。

范围：

- 最小：50 词/章。
- 最大：150 词/章。

老师选择英语难度后，系统按难度填入默认目标词数：

| 难度 | 默认目标词数 |
| --- | --- |
| A1 | 50 |
| A2 | 70 |
| B1 | 90 |
| B2 | 110 |
| C1 | 130 |
| C2 | 150 |

输入旁显示短提示：

```text
当前难度推荐 90 词/章，可在 50-150 间调整。
```

老师手动改过某章目标词数后，后续切换难度不再覆盖该章目标词数。

#### 知识点

每章只有一个“知识点”多选，不区分主知识点和补充知识点。

规则：

- 每章至少选择 1 个知识点。
- 可选择多个知识点。
- 知识点来自预设知识点库。
- 未选择知识点时不能确认进入下一步。

#### 正文模式

正文模式为二选一：

- 无题目，默认值。
- 加入内嵌题。

选择“无题目”时：

- 后续文案与练习阶段生成 clean reading。
- 正文中不嵌入填空、选择或词汇题。
- 当前章预览展示纯正文 slide。

选择“加入内嵌题”时：

- 展示内嵌题型和题量配置。
- 支持题型：选择题、填空题、词汇题。
- 匹配题不能用于阅读内嵌题。
- 当前章预览展示带内嵌题的正文 slide。

#### 章节练习

章节练习默认开启，但老师可以关闭。

开启时配置：

- 题型：选择题、填空题、词汇题、匹配题。
- 题量。

关闭时：

- 本章不生成章节练习。
- 当前章预览不展示章节练习页。

### 右侧：课后练习配置

课后练习作为左侧独立入口，不混入单章配置。

课后练习默认开启，老师可以关闭。

开启时展示：

- 知识点。
- 题型。
- 题量。
- 课后练习 PPT Slide 式预览。

课后练习知识点默认取所有章节已选知识点的合集。

规则：

- 如果老师没有手动改过课后练习知识点，章节知识点变化时自动同步合集。
- 如果老师手动删减过课后练习知识点，章节知识点变化后不自动覆盖，只提示：

```text
课后练习知识点可能需要检查。
```

- 课后练习知识点只能从章节知识点合集里删减，不能新增章节外知识点。
- 课后练习关闭时，不生成课后练习，也不展示课后练习预览。

## PPT Slide 式预览

预览只服务当前选中对象，不做全课预览。

章节预览包括：

- 正文页。
- 章节练习页，仅在章节练习开启时可切换查看。

课后练习预览包括：

- 课后练习页。

预览要求：

- 使用 16:9 PPT slide 外观。
- 使用模板内容，不调用 AI，不生成真实正文或真实题目。
- 根据当前配置展示大致形态：纯正文、内嵌题正文、章节练习、课后练习。
- 根据目标词数估算文本密度。
- 根据题型显示对应题目样式。
- 不展示 prompt、JSON、schema、模型、provider 或内部技术错误。

预览示例不作为下游生成真相源。下游真实内容必须由阶段四基于已确认教学规划生成。

## 推荐值与 touched 规则

系统只在必要时自动填推荐值，且不得覆盖老师已手动修改的字段。

首次进入：

- 英语难度为 `null`，不默认。
- 每章目标词数为 `null`，等待选择难度后填入。
- 每章知识点为空。
- 每章正文模式默认为 `none`。
- 每章章节练习默认开启。
- 课后练习默认开启。

选择英语难度后：

- 为未手动修改目标词数字段的章节填入默认目标词数。
- 为未手动修改练习配置的章节填入推荐题型和题量。
- 为未手动修改课后练习配置的字段填入推荐题型和题量。

老师手动修改字段后，该字段标记为 touched。后续切换难度不覆盖 touched 字段。

切换难度后，如果存在保留的手动配置，页面显示短提示：

```text
部分配置保留了你的修改。
```

不提供“重新应用推荐配置”按钮。老师需要自行调整。

## 题型范围

```ts
type ExerciseType = "choice" | "blank" | "vocab" | "matching";
```

使用范围：

| 题型 | 阅读内嵌题 | 章节练习 | 课后练习 |
| --- | --- | --- | --- |
| 选择题 | 支持 | 支持 | 支持 |
| 填空题 | 支持 | 支持 | 支持 |
| 词汇题 | 支持 | 支持 | 支持 |
| 匹配题 | 不支持 | 支持 | 支持 |

## 推荐题量

题量根据课程时长初始化。推荐值只用于降低老师配置成本，老师可以修改。

| 课程时长 | 阅读内嵌题 | 章节练习 | 课后练习 |
| --- | --- | --- | --- |
| 30 分钟 | 3 | 3 | 6 |
| 45 分钟 | 4 | 4 | 8 |
| 60 分钟 | 5 | 5 | 10 |

题量限制：

- 阅读内嵌题：1-8，仅在正文模式为“加入内嵌题”时有效。
- 章节练习：1-10，仅在章节练习开启时有效。
- 课后练习：1-20，仅在课后练习开启时有效。

如果某类练习开启，题型至少选择 1 个，题量至少为 1。

## 保存和确认

本阶段区分“保存草稿”和“确认并进入文案与练习”。

### 保存草稿

保存草稿：

- 保存当前教学规划。
- 不推进课程阶段。
- 不重置文案与练习、视觉资源或预览。
- 保存失败时前端保留所有输入。

保存失败提示：

```text
保存失败，请重试。
```

### 确认并进入文案与练习

确认动作：

- 校验教学规划完整性。
- 标记教学规划为 `confirmed`。
- 推进课程 `currentStage = "content"`。
- 跳转到文案与练习阶段。

如果下游已经存在文案、练习、视觉资源或预览配置，再次确认新教学规划时必须二次确认：

```text
确认后会重置已生成的文案、练习和视觉资源。
```

按钮：

- 取消
- 继续确认

重置必须由后端事务完成。事务失败时，旧教学规划确认状态和旧下游内容保持不变。

确认失败提示：

```text
确认失败，已有内容未改变。
```

## API 合同

### `GET /api/courses/:id/teaching-plan`

读取教学规划。

行为：

- 如果教学规划已存在，返回当前规划。
- 如果教学规划不存在，但故事大纲已确认，根据故事大纲创建草稿壳子并返回。
- 草稿壳子只包含章节 id、默认正文模式、默认章节练习开启、默认课后练习开启；不默认英语难度，不默认知识点。
- 如果故事大纲不存在或未确认，返回 `400`。

响应：

```ts
{
  plan: TeachingPlan;
}
```

### `PUT /api/courses/:id/teaching-plan`

保存教学规划草稿。

请求：

```ts
{
  plan: TeachingPlan;
}
```

行为：

- 校验课程存在。
- 校验故事大纲已确认。
- 校验章节 id 与故事大纲一致。
- 保存草稿。
- 不重置下游。
- 不推进阶段。

响应：

```ts
{
  plan: TeachingPlan;
}
```

### `POST /api/courses/:id/teaching-plan/confirm`

确认教学规划并进入文案与练习。

请求：

```ts
{
  resetDownstream?: boolean;
}
```

行为：

- 校验课程存在。
- 校验故事大纲已确认。
- 校验教学规划完整。
- 如果存在下游内容且请求未带 `resetDownstream = true`，返回 `409`。
- 带 `resetDownstream = true` 后，在单个事务中确认教学规划、推进阶段并重置下游。

响应：

```ts
{
  plan: TeachingPlan;
  course: {
    id: string;
    currentStage: "content";
  };
}
```

失败：

- `400 { message: "请先确认故事大纲" }`
- `400 { message: "教学规划信息不完整" }`
- `404 { message: "课程不存在" }`
- `409 { message: "确认后会重置已生成的文案、练习和视觉资源" }`
- `500 { message: "教学规划确认失败" }`

## 数据结构

建议新增 `CourseTeachingPlan`，一课一条。

```ts
type TeachingPlan = {
  courseId: string;
  status: "draft" | "confirmed";
  englishLevel: "A1" | "A2" | "B1" | "B2" | "C1" | "C2" | null;
  chapters: TeachingPlanChapter[];
  afterClassPractice: AfterClassPracticeConfig;
  updatedAt: string;
  confirmedAt: string | null;
};

type TeachingPlanChapter = {
  outlineChapterId: string;
  targetWordCount: number | null;
  knowledgePointIds: string[];
  readingExerciseMode: "none" | "embedded";
  embeddedExercises: ExerciseConfig;
  chapterPractice: PracticeConfig;
  touched: {
    targetWordCount: boolean;
    readingExerciseMode: boolean;
    embeddedExercises: boolean;
    chapterPractice: boolean;
  };
};

type ExerciseConfig = {
  enabled: boolean;
  types: Array<"choice" | "blank" | "vocab">;
  count: number;
};

type PracticeConfig = {
  enabled: boolean;
  types: Array<"choice" | "blank" | "vocab" | "matching">;
  count: number;
};

type AfterClassPracticeConfig = {
  enabled: boolean;
  knowledgePointIds: string[];
  practice: PracticeConfig;
  touched: {
    knowledgePointIds: boolean;
    practice: boolean;
  };
};
```

## 校验规则

确认进入下一步前必须满足：

- 故事大纲已确认。
- `englishLevel` 必填。
- 每章 `targetWordCount` 在 50-150。
- 每章至少选择 1 个知识点。
- 如果 `readingExerciseMode = "embedded"`：
  - `embeddedExercises.enabled = true`。
  - 题型至少 1 个。
  - 题量至少 1。
  - 题型只能是选择题、填空题、词汇题。
- 如果章节练习开启：
  - 题型至少 1 个。
  - 题量至少 1。
  - 题型只能是选择题、填空题、词汇题、匹配题。
- 如果课后练习开启：
  - 知识点至少 1 个。
  - 题型至少 1 个。
  - 题量至少 1。
  - 知识点必须来自章节知识点合集。

校验失败时，页面定位到第一个问题所在的章节或课后练习入口。

示例提示：

```text
第 2 章还没有选择知识点。
```

## 下游边界

本阶段不生成：

- 英文阅读正文。
- 阅读内嵌题真实题目。
- 章节练习真实题目。
- 课后练习真实题目。
- 答案。
- 解析。
- 图片 prompt。
- 课件页面。

阶段四“文案与练习”必须严格消费本阶段已确认配置：

- 不生成老师未选择的知识点。
- 不生成老师未选择的题型。
- 正文模式为“无题目”的章节，不生成阅读内嵌题。
- 章节练习关闭的章节，不生成章节练习。
- 课后练习关闭时，不生成课后练习。

## 失败恢复

- 章节切换不丢失未保存本地修改。
- 离开页面或返回上一步时，如果有未保存修改，提示确认。
- 保存失败不清空输入，不推进阶段，不重置下游。
- 确认校验失败不推进阶段。
- 确认后重置下游失败时，保留旧教学规划确认状态和旧下游内容。
- 修改故事大纲并重新确认后，必须重置教学规划及后续内容。
- `GET /teaching-plan` 发现故事大纲章节 id 与已有规划不一致时，不做隐式修补，应返回需要重新创建规划草稿的错误。

## 验收标准

- 阶段三不调用 AI。
- 首次进入不默认英语难度。
- 选择难度后自动填入未修改章节的目标词数和推荐练习配置。
- 目标词数范围为 50-150。
- 知识点按章多选，不分主知识点和补充知识点。
- 每章至少 1 个知识点。
- 正文默认无题目，可切换为加入内嵌题。
- 章节练习默认开启，可关闭。
- 课后练习默认开启，可关闭。
- 课后练习知识点默认来自所有章节知识点合集。
- 匹配题不能用于阅读内嵌题。
- 当前章和课后练习使用 PPT Slide 式预览。
- 不展示全课预览或结构统计长列表。
- 保存草稿不重置下游。
- 确认进入下一步才重置下游，并有二次确认。
- 老师手动改过的字段不会被切换难度自动覆盖。
