# 课程创建 V2 阶段一：授课对象确认

## 模块目标

阶段一只确认这节课给谁上、由谁上、上多久，以及课程在管理侧如何命名。

阶段一不做内容决策，不产生 AI 费用。

## 设计原则

- 老师不需要在第一步思考故事、难度、知识点、题型、第三方人物或视觉风格。
- 页面不出现说明书式长文案。
- 通过选择器、人物卡片、缺失标签、流程位置和按钮状态完成引导。
- 人物信息缺失时允许就地补全，避免跳转到人物档案页再返回。

## 字段

必填：

- 课程名称
- 老师：单选 1 位
- 学生：至少 1 位
- 课程时长

不在本阶段收集：

- 英语难度
- 全局知识点
- 章节知识点
- 故事主题
- 第三方人物 / IP / 参考剧情
- 题型配置
- 章节练习 / 课后练习配置
- 视觉风格

## 课程名称

课程名称由老师在阶段一填写，后续 AI 不覆盖。

命名边界：

- `Course.title` 是课程管理名称。
- 后续课程方案可生成故事标题或课件展示标题。
- 故事标题和课件展示标题不回写 `Course.title`。
- 预览发布阶段可以允许老师调整展示标题，但不改变管理侧课程名称，除非用户明确编辑课程名称。

## 老师和学生选择

现有“展示全部人物后勾选”的方式不适合继续使用。

V2 改为：

- 页面主体展示已选老师和已选学生。
- 使用“添加老师”“添加学生”按钮打开选择弹层或抽屉。
- 选择器支持搜索。
- 选择器支持最近使用。
- 老师为单选。
- 学生为多选。
- 已选人物以紧凑卡片展示。

人物卡片只展示决策所需信息：

- 中文名 / 英文名
- 年龄
- 性别
- 兴趣摘要
- 外貌摘要
- 信息缺失标签
- 编辑入口

## 就地编辑人物

老师和学生卡片提供编辑按钮。

点击后在当前页面打开右侧抽屉，支持修改会影响 AI 生成的信息：

- 中文名
- 英文名
- 年龄
- 性别
- 外貌描述
- 兴趣
- 备注

保存后：

- 更新人物档案。
- 当前课程选择中的人物信息同步刷新。
- 不跳转到人物档案页。

## 信息完整度

人物信息缺失不阻断进入下一步，但需要短标签提示。

示例标签：

- 缺英文名
- 缺年龄
- 缺外貌

缺失标签只提示影响，不弹长说明。老师可以点击标签或编辑按钮补全。

## 页面行为

初始状态：

- 课程名称输入框为空。
- 老师区域显示“添加老师”。
- 学生区域显示“添加学生”。
- 课程时长未选择。
- 下一步按钮禁用。

下一步按钮启用条件：

- 课程名称非空。
- 已选择 1 位老师。
- 已选择至少 1 位学生。
- 已选择课程时长。

禁用时只展示最短原因，例如：

- 填写课程名称
- 添加老师
- 添加学生
- 选择时长

## API 边界

V2 API 使用 `/api/v2/...`。

### `POST /api/v2/courses`

创建 `workflowMode = "plan_based"` 的课程。

请求：

```ts
type CourseAudienceInput = {
  title: string;
  teacherId: string;
  studentIds: string[];
  durationMinutes: 30 | 45 | 60;
};
```

响应：

```ts
{
  course: {
    id: string;
    workflowMode: "plan_based";
  };
}
```

失败：

- `400 { message: "课程名称不能为空" }`
- `400 { message: "请选择老师" }`
- `400 { message: "请选择学生" }`
- `400 { message: "请选择课程时长" }`
- `404 { message: "人物不存在" }`
- `500 { message: "课程创建失败" }`

### `PUT /api/v2/courses/:id/audience`

更新阶段一信息。

请求同 `CourseAudienceInput`。

行为：

- 只允许更新 `workflowMode = "plan_based"` 的课程。
- 修改老师、学生或课程时长后，不自动删除下游内容。
- 若后续已经生成课程方案，API 返回下游可能过期的状态，具体失效策略在课程方案模块确认。

失败：

- `400 { message: "课程信息不完整" }`
- `404 { message: "课程不存在" }`
- `409 { message: "该课程不属于 V2 创建流程" }`
- `500 { message: "课程保存失败" }`

### 人物选择和编辑 API

阶段一复用或新增 V2 包装 API 的具体方式待实现前确认。

产品要求：

- 支持搜索人物。
- 支持按角色过滤。
- 支持最近使用排序。
- 支持就地编辑人物。

## 数据结构

复用：

- `Course`
- `Person`
- `CoursePerson`

建议新增：

```prisma
enum CourseWorkflowMode {
  legacy
  plan_based
}
```

`Course` 增加：

```prisma
workflowMode CourseWorkflowMode @default(legacy)
```

阶段一不新增课程方案、练习、视觉资产相关表。

## 失败恢复

- 创建课程失败：不创建半完成课程，用户保留表单内容后重试。
- 更新阶段一失败：不改变已有课程信息，用户保留当前编辑后重试。
- 人物编辑失败：不改变当前卡片展示，抽屉保留用户输入后重试。
- 已生成下游内容后修改授课对象：不在阶段一直接清空下游内容，必须在课程方案阶段定义过期提示和重生成边界。

## 验收标准

- 老师必须填写课程名称，AI 后续不会覆盖该名称。
- 老师选择不再使用全量列表直接勾选。
- 学生选择不再使用全量列表直接勾选。
- 支持通过添加弹层或抽屉搜索并选择人物。
- 支持在当前页面就地修改老师和学生资料。
- 人物资料缺失以短标签提示，不使用长段说明。
- 阶段一不出现难度、知识点、题型、故事、IP 或视觉风格。
- 阶段一不产生 AI 费用。
- 创建的新课程标记为 `workflowMode = "plan_based"`。
